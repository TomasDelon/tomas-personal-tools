HERRAMIENTAS PERSONALES DE TOMAS DELON

Tomas Google Tasks

Conector personal para gestionar listas y tareas de Google Tasks desde asistentes y para ejecutar el flujo local Manim → Desktop Commander → YouTube.

Qué hace

Google Tasks permite consultar, crear, editar y completar tareas por instrucción del propietario. Manim renderiza animaciones matemáticas en el equipo atlas y sube el MP4 a YouTube como No listado cuando el propietario lo solicita. El asistente devuelve el enlace del vídeo.

Acceso

Uso privado del propietario, mediante consentimiento OAuth y los permisos necesarios de cada integración. El cliente Manim solicita únicamente youtube.upload. No hay registro público ni se solicita la contraseña de Google.

Conexiones personales administradas por el propietario mediante sus clientes autorizados.
